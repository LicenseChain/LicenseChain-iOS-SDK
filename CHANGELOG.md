# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

- Published CocoaPods trunk pod `LicenseChainiOS` version 1.0.3 (tag `v1.0.3`).

- Renamed CocoaPods pod to `LicenseChainiOS` to avoid iOS/macOS trunk name collision.

## [1.0.2] - 2026-10-12

- Synced LicenseChain.podspec to Elastic-2.0, iOS 15, Swift 5.9, and tag v1.0.2.

## [1.0.1] - 2026-10-10

- Relicensed public surface under Elastic License 2.0 (ELv2).
- Raised Swift tools version to 5.9 and minimum iOS platform to 15.0.
- Added Dependabot for GitHub Actions. Build/test requires macOS with Xcode.

## [1.0.0] - 2026-04-06

- Initial public SDK surface with repository documentation kit.
